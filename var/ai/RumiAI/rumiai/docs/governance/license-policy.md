# RumiAI License & Open Source Policy

Versione: 0.1
Stato: Foundation Release Draft

---

# 1. Scopo

Questo documento definisce la politica di licenza e gestione open source di RumiAI.

Gli obiettivi sono:

* chiarire i diritti di utilizzo;
* proteggere il progetto;
* facilitare contributi;
* mantenere trasparenza.
